# Glossary

| Термін | Значення |
| --- | --- |
| Company project | Playwright-проект, що відповідає одній компанії з дампу; тести тегнуті `@<company>`; `workers: 1` |
| Dump | Анонімізована копія прод-бази, заливається на Precorino раз на 2–4 тижні |
| Precorino | Тестове середовище |
| pre\_dev | Гілкове середовище девелопера, без accounts-мікросервісу |
| idn | Людський номер документа в межах компанії, на відміну від `id` в БД |
| DCF / ICF / SCF | Кастомні поля документа / позиції / постачальника |
| LE | Legal entity |
| PR / RFP / PO / SPO / WR | Purchase requisition / request for proposal / purchase order / service PO / warehouse request |
| Control | Адмін-панель `control.precorino.com`, керує акаунтами, планами, feature-флагами; у TAF це `ControlClient` |
| storageState | Збережена сесія браузера, Playwright підставляє її замість логіну |
| Machine-time | Сума тривалостей усіх тестів; те, що множиться на кількість гілок і впирається в Jenkins |
| Wall-clock | Реальний час прогону; залежить від воркерів і пакування |
| Flaky | Тест, що впав і пройшов з ретраю; окрема метрика, не "зелений" і не "червоний" |
| Контрольний показник | Кількість входжень патерну-боргу в коді; перевіряється в CI і може лише зменшуватись; пара до lint-правила, яке забороняє нові входження |
| Codemod | Скрипт, що робить одну правку в сотнях файлів через синтаксичне дерево, а не текст |
| Strangler | Стратегія: нова форма поруч зі старою, старе вмирає по мірі переїзду, без big-bang |
