# ADR-003: Репортинг знімається з тестового коду
Статус: Draft
Дата: 2026-09-16

## Контекст
Тестовий код прив'язаний до Allure: `allure.step` 10 243, `test.step` 0, плюс description/suite/displayName. Кроки не видно в trace viewer і в тексті помилки; заміна репортера означала б правку 12 тисяч рядків. Вкладені кроки підписують копіпасту preparation замість абстракції. Цифри: `01-context/taf-as-is.md`.

Playwright сильніший усередині одного падіння (trace viewer, нуль інфраструктури, кроки в помилці). Allure сильніший між прогонами (історія, категорії, suite-ієрархія), але половину цього команда вже відтворила у власному дашборді.

## Рішення
У коді лише `test.step`, теги, `test.info().attach/annotations`. Репортери підключаються тільки в конфігу; Allure лишається, поки команда його читає. Обгортка HTTP у `requests.ts` зберігається на `test.step` + `attach`. Lint проти імпорту `allure-js-commons` поза `requests.ts`. Правила кроків: `02-principles/conventions.md`.

## Наслідки
- Вибір репортера це один рядок конфігу.
- Категорії падінь або з Allure, або з JSON за день, якщо Allure приберуть.

## Міграція
Codemod у три проходи. Задача T1-11.

## Відхилені альтернативи
- Лишити як є: прив'язка до репортера.
- Прибрати Allure зараз: зайвий конфлікт із командою до появи категорій у дашборді.
