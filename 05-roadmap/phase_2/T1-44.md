# T1-44. Найдовші тести — не довші за 2 хв на тест

Етап 2. Фаза 1, трек B. Швидкість. ADR: —. Asana: нема. Додано в план 2026-11-17.

## Біль

Довгий тест тримає воркер: нічний закінчується тоді, коли закінчується найдовша черга, і кілька тестів по 5–10 хв на кінці прогону подовжують його для всіх. У довгих тестах частіше живуть таймаути й зависання, а перезапуск такого тесту коштує стільки ж.

## Що зробити

1. Зняти список з AQA Metrics → Per test: тести понад 2 хв за останні нічні, найдовші першими; записати базу (скільки тестів понад 2 хв, найдовший) у картку.
2. Для кожного тесту зі списку назвати причину: підготовка стану через UI замість API, очікування, обсяг даних, кілька сценаріїв в одному тесті.
3. Правки за причиною: підготовка через API (разом із T1-09, T1-10, T1-17), розбиття на кілька тестів, прибирання зайвих очікувань.
4. Після кожної групи правок — порівняти з Per test за наступний нічний.

## Готово, коли

Жоден тест у Per test за останні нічні не триває понад 2 хв. Тест, що знову перевищив 2 хв, видно в Per test, і він отримує задачу.

## Метрика

Кількість тестів понад 2 хв; тривалість найдовшого тесту, хв.
