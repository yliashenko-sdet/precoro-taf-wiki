# Картки задач

Одна картка на задачу з `../plan-to-tasks.md`. Картка пишеться перед стартом задачі, для найближчого етапу, і є її definition of ready: без картки задача не береться. Картки для пізніших етапів не пишуться наперед, бо застаріють.

Формат: Біль → Контекст (що є зараз, файли) → Підхід (кроки) → Готово, коли → Ризики і залежності → Оцінка.

Які задачі в якому етапі: колонка "Етап" у `../plan-to-tasks.md`.
