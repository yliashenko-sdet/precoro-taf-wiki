## Контекст
На `release` 3 помилки; у робочому дереві після правок Yevhen лишилось 2. Відомі: відсутній локатор `remove_budget_btn_part` у `BaseDocumentLocators` (тип `DocumentEditLocators` його вимагає), `successFlashAppeared` не існує в `UserManagementPage` (`test_users.spec.ts:1044`), невикористаний `page` у `test_supplier.spec.ts:3007`. `tsconfig.json` отримав `noEmit: true`.

## Підхід
1. `npx tsc --noEmit`, список помилок.
2. Кожна помилка чиниться по суті, не через `// @ts-ignore`: локатор додати в базові локатори або прибрати з типу; метод або додати в сторінку, або замінити на існуючий `expectSuccessFlash`-подібний; невикористаний параметр прибрати.
3. Гейт там, де змінюється TAF: PR у TAF-репозиторій сьогодні не запускає нічого. Варіант A: GitHub Actions у репозиторії TAF (`typecheck`, `lint`, показники), без Jenkins і без середовища; потребує лише дозволу на Actions для приватного репо. Варіант B: джоба на qa Jenkins, що слухає PR у TAF через GitHub-webhook; власний Jenkins QA, пів години Максима. Обидва варіанти не чіпають dev Jenkins і Jenkinsfile продукту.
4. Синхронізувати з робочою гілкою команди `fix/11-09-2026`: перевірити, що там теж 0.
