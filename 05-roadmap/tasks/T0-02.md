## Підхід
Правило `eqeqeq: 'always'` не змінюється. Кожне нестроге порівняння виправляється за типом операнда (сухий запуск на TypeScript API):

1. Тип точний, 13 місць: `T | null` → `!== null`, `T | undefined` → `!== undefined`, `T | null | undefined` → довга форма, число з числом → `!==`.
2. Мертва перевірка, 31 місце: `(r) => r != null && r.length > 0 && ...` в умовах `DataBase.waitForResult`. Умова викликається лише з результатом `queryFn()`, який за типом завжди масив, тому `r != null &&` прибирається.
3. Тип `unknown`, 33 місця (значення з MySQL, API, `?.`): довга форма `x !== null && x !== undefined`, як у наявних 84 місцях.

Решта 4 помилки вручну:
- `icf_page.ts`: невикористаний `catch (error)` → `catch`.
- `scf_fixtures.ts`: порожній `catch (e) {}` у прибиранні → лог, як у сусідньому блоці (AUTO-7817).
- `mixin.ts`: `Constructor<T = {}>` → `T = object`.
- `test_reports.spec.ts`: `reportsPage.waitForPageLoad()` без `await` → з `await`. Єдина зміна поведінки: тест почне справді чекати завантаження.

Warnings 57: 28 `no-explicit-any` і 16 `explicit-function-return-type` поза mixin-ами виправляються (типи, без зміни логіки). 13 `explicit-function-return-type` у mixin-ах лишаються: зникнуть разом із mixin-ами в T3-05. Правила лишаються `warn`, поки T3-05 не закрите.

Гейт: крок `npm run lint` у `.github/workflows/quality.yml` (T0-01). Нових правил не вмикати; вони вмикаються з codemod-ами (`06-playbooks/playbook-codemod-metrics.md`).
