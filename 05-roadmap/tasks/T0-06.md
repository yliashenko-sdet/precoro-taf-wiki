# T0-06. Перезапуск лише впалих тестів у Jenkins
Біль: P2. ADR-006. Виконавець: інфра-AQA, апрув Олександра або девів.

## Контекст
Playwright 1.59 підтримує `--last-failed` через `test-results/.last-run.json`. Локально команда цим користується (`docker-compose.yml`). На Jenkins файл не переживає білд. Jenkinsfile у репозиторії продукту. Дві тестові стадії: `Test End-to-End` (smoke + модуль) і `Full Run Tests: playwright`.

## Підхід
1. Після кожної тестової стадії `archiveArtifacts test-results/.last-run.json` з іменем стадії.
2. Параметр джоби `RERUN_FAILED_ONLY` (boolean). Якщо true: `copyArtifacts` з останнього білда тієї ж гілки, файл у `test-results/`, команда з `--last-failed`; стадія, чий файл порожній або відсутній, пропускається з повідомленням.
3. Пост бота позначає rerun; `metrics-reporter` отримує `RERUN=1` в env і пише це в `history.jsonl`, щоб дашборд не змішував.
4. Заміряти час перезапуску з урахуванням bootstrap середовища; цифру в `pain-to-plan.md`.
5. Повідомити девелоперів у каналі, як користуватись.

## Готово, коли
Девелопер сам перезапускає лише впалі; rerun видно в метриках; час заміряний.

## Ризики
`copyArtifacts` бере не той білд, якщо гілка перезбиралась паралельно; брати останній завершений із тим же коммітом. Flaky-тест, що пройшов на rerun, не має ставати "зеленим" у статистиці: rerun позначений.
