# T0-18. Каталог падінь із каналу Jenkins Failed Builds
Біль: P1. Статус: wip, рівень стадій зроблено.

## Контекст
Експорт без тредів проаналізовано: `01-context/jenkins-failed-builds.md`. Лишається рівень тредів: там розбір "фейл чи флейк".

## Підхід
1. Отримати експорт із тредами або пройти останні 4–6 тижнів у Slack. У Slack: спершу скріншот, що фокус у пошуку, не в композері.
2. На кожен тред із тестовим падінням: категорія (продукт / флейк / середовище / дані / спільний UI / людина), хто розбирав, скільки часу до вирішення, чи був перезапуск.
3. Таблиця в `metrics.md`: частка категорій, медіана часу до відповіді AQA, список тестів, що фігурують у ≥2 тредах.
4. Ці частки стають baseline для T2-07 і аргументом для розмови про ретраї (ADR-006).

## Готово, коли
Частки категорій і повторні порушники в `metrics.md`.

Оцінка: 1 день.
