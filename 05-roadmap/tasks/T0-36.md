## Як на GHA (`precoro/.github/workflows/pr-checks.yml`, джоби `build` і `e2e`)

1. Образ з `docker/ci/Dockerfile` (секрети збірки: `composer_auth`, `translain_token`).
2. `.env.ci.infisical` (з repo secret) + `.env.ci`.
3. `docker compose -f docker-compose-ci.yml up -d --wait`; `127.0.0.1 rustfs` в `/etc/hosts`; тег `opensearch-sync` — найновіший у DO registry.
4. `.github/scripts/import-seed.sh` → `.github/scripts/init-app.sh`.
5. TAF: `RUN_ENV=branch`, `APP_BASE_URL=http://localhost:8080`, `MAILPIT_URL=http://localhost:8025`, `DATABASE_URL` на MySQL стеку (`127.0.0.1:3306/precoro`, користувач і пароль із compose продукту), порожня basic auth.

## Локально робимо так само, з трьома відмінностями

- Образ збирається локально тим самим `docker/ci/Dockerfile`; composer-токен із закоміченого `auth.json` продукту, токен перекладів порожній.
- `.env.ci.infisical` — `infisical export --env=e2e-tests` або файл від GQA (без нього стек віддає 500 на кожній сторінці).
- `opensearch-sync:latest-staging` (`develop` ламає індекс WR); seed — найсвіжіший `autotests_seed_*.sql.gz` у корені продукту.

Без правок у робочому дереві продукту. Три наші змінні TAF лишаються як є. Один раз на машині: `docker login registry.digitalocean.com`, `127.0.0.1 rustfs` в `/etc/hosts`.
