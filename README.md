# Precoro TAF 2.0 Wiki

Єдине місце, де зафіксовано, **що** ми змінюємо в тестовому фреймворку Precoro, **чому** і **як саме**. Вікі одночасно є контекстом для Claude Code і документом для команди.

Репозиторій TAF: `precoro-e2e-playwright` (TypeScript + Playwright, переклад із Python + Selenium у березні 2026).

## Як користуватись

- **Перед будь-якою роботою над TAF** прочитай `02-principles/principles.md` і `05-roadmap/phases.md`. Це п'ять хвилин, і це те, що відрізняє "правильно" від "як було".
- **Перед зміною конкретного шару** відкрий відповідний файл у `04-target/`. Там цільова форма і межа "що не чіпаємо".
- **Будь-яке нове рішення** це новий ADR у `03-decisions/` за шаблоном. Без ADR рішення не існує.
- **Кожна задача в беклог** береться з `05-roadmap/backlog.md` і має критерій готовності та контрольний лічильник.
- **Кінець робочої сесії**: рядок у `99-log.md`, оновлення `07-open-questions.md`, якщо щось закрилось або відкрилось.

## Підключення до Claude Code

Скопіювати теку в репозиторій як `docs/taf-2.0/` і додати в `CLAUDE.md` репозиторію:

```
## TAF 2.0
Перед роботою над кодом прочитай docs/taf-2.0/README.md і дотримуйся docs/taf-2.0/02-principles/.
Рішення фіксуються в docs/taf-2.0/03-decisions/ як ADR. Не пропонуй патерни, заборонені в 02-principles/conventions.md.
```

## Правило вікі
Один факт живе в одному місці, решта посилається: цифри в `01-context`, правила в `02-principles`, "чому" в `03-decisions`, "як виглядає" в `04-target`, порядок і задачі в `05-roadmap`, лічильники в `05-roadmap/metrics.md`, інструкції в `06-playbooks`.

## Карта

| Розділ | Що там | Коли читати |
|---|---|---|
| `01-context/` | Продукт, команда, енви, CI, аудит as-is із цифрами, перелік ендпоінтів Swagger | Онбординг, перевірка фактів |
| `02-principles/` | Принципи TAF 2.0, конвенції написання тестів, Definition of Done | Завжди |
| `03-decisions/` | ADR: одне рішення на файл, зі статусом | Перед тим як щось змінювати "по-своєму" |
| `04-target/` | Цільова архітектура по шарах: конфіг, фікстури, API-клієнт, дані, page-шар, CI | Перед роботою над шаром |
| `05-roadmap/` | Фази, метрики, беклог задач | Планування |
| `06-playbooks/` | Codemod і контрольні лічильники, вимірюваний результат тижня, як писати тест, як розбирати падіння | Під час роботи |
| `07-open-questions.md` | Що ще не вирішено і від кого залежить | Щотижня |
| `99-log.md` | Журнал рішень і подій | Кінець сесії |
